# Aplikasi Booking Servis Bengkel

Sistem booking berbasis Web dan Mobile dengan 3 role: pelanggan, admin, super_admin.

## Struktur Monorepo

```
bengkel-app/
├── backend/          → Express.js REST API + Supabase SDK
├── frontend-web/     → Next.js 14 App Router + Tailwind CSS
└── frontend-mobile/  → React Native Expo + NativeWind
```

## Cara Menjalankan

Lihat README.md di masing-masing folder untuk petunjuk lengkap.
